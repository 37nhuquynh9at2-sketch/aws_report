# Event Report (13/06/2026)

## Purpose of the Event

The event was organized with the purpose of helping students and young engineers:

- Gain a better understanding of real-world working environments in Cloud, AI, DevOps, and Data Analytics fields.
- Learn about recruitment processes, required skills, and career development paths in the technology industry.
- Connect with the technology community through practical experiences shared by engineers working at technology companies and AWS Partners.
- Develop system thinking, professional working culture, and problem-solving skills in an enterprise environment.

# Key Topics

## 1. DevOps - Real-world Role and Job Market

### Overview of DevOps Responsibilities

The session provided a practical view of DevOps work. DevOps is not only about building CI/CD pipelines or managing Docker and Kubernetes, but also about solving real operational problems in software systems.

Common DevOps responsibilities include:

- Handling environment issues from testing teams.
- Troubleshooting system performance problems.
- Ensuring system security.
- Optimizing Cloud infrastructure costs.
- Supporting continuous system operation.

### Required Knowledge and Skills

Important technical foundations for DevOps include:

- Linux.
- Networking.
- Programming languages such as Python and Golang.
- Git.
- CI/CD.
- Containers.

Besides technical skills, DevOps engineers need:

- System thinking instead of only completing assigned tasks.
- Understanding the root cause before applying solutions.
- Automating repetitive tasks.
- Effective communication and collaboration skills.

## 2. Journey from Student to AWS Partner

The speaker shared a development roadmap from students to professional Cloud engineers:

1. **Student Curiosity** - Starting from curiosity and the desire to explore technology.
2. **First Cloud Journey** - Finding suitable learning environments.
3. **Workshop & Community** - Learning through technology communities.
4. **Hands-on Labs** - Practicing through real-world exercises.
5. **School Projects** - Applying knowledge to practical projects.
6. **Portfolio** - Building personal projects to demonstrate skills.
7. **AWS Partner** - Solving real-world business problems.
8. **Share Back** - Sharing knowledge with the next generation.

The event also introduced student support programs:

- AWS Student Builder Group.
- AWS Cloud Clubs.
- First Cloud AI Journey Program.

These programs help students build Cloud infrastructure knowledge through:

- IAM.
- VPC.
- EC2.
- Cost Management.
- Observability.

## 3. Real-world Data Analytics Engineer Experience

### Applications of Data Analytics in Businesses

The speaker shared how Data Analytics is applied in different industries:

**E-commerce/Logistics:**

- Building periodic reports.
- Designing dashboards to monitor trends.
- Analyzing revenue and operational costs.

**Manufacturing/FMCG:**

- Analyzing IoT and machine data.
- Optimizing production costs.
- Supporting digital transformation.

### Important Skills

A Data Analytics Engineer needs to develop:

- Critical Thinking.
- Communication.
- Data Storytelling.
- Problem Solving.

### Career Development Model

The career growth model includes five levels:

- **Follower:** Performing tasks based on instructions.
- **Learner:** Actively learning and asking deeper questions.
- **Problem Solver:** Analyzing problems and proposing solutions.
- **System Thinker:** Understanding the overall system and business impact.
- **Super Star:** Providing strategic direction and mentoring others.

---

## 4. Recruitment Process and Enterprise Culture

### Recruitment Process in Multinational Companies

The recruitment process usually includes four stages:

### 1. Screening & Initial Interview

- Resume screening through ATS.
- Basic interview, often in English.

### 2. Technical Assessment

- Algorithm and logical thinking tests.
- Problem-solving evaluation.

### 3. Technical Interview

- Evaluation of professional knowledge.
- Discussion about real-world technical problems.

### 4. Culture Fit Interview

- Assessment of compatibility with company values and culture.

### Enterprise Working Culture

Important working cultures introduced:

**No-Blame Post-Mortem**

- Focus on finding system problems instead of blaming individuals when incidents happen.

**Caring & Inclusive Culture**

- Respect diversity.
- Build a people-centered working environment.
