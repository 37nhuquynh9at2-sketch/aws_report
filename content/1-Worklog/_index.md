During the internship period from **08/06/2026 to 31/07/2026**, I participated in the **First Cloud AI Journey** program organized by **AWS Study Group**. The program was conducted over **08 weeks**, focusing on learning fundamental knowledge about **Amazon Web Services (AWS)** and applying the acquired knowledge to develop the **Library Management Website** project.

Throughout the internship, I learned about important AWS services such as **IAM, VPC, EC2, S3, RDS, CloudWatch, and security services**. Besides completing AWS lessons and hands-on practices, I worked with my team to analyze system requirements, finalize technologies, design interfaces, and develop Frontend features for the project.

The weekly work contents were as follows:

**Week 1:** Get familiar with the First Cloud AI Journey program, learn about AWS Cloud, create an AWS Account, configure IAM, set up AWS Budgets, and explore AWS Management Console.

**Week 2:** Learn about Amazon VPC and Amazon EC2, practice deploying servers on AWS, and finalize the topic of the Library Management Website project.

**Week 3:** Learn AWS CLI, Amazon S3, Amazon RDS, and CloudWatch, and perform functional requirement analysis for the system.

**Week 4:** Learn AWS storage services, participate in system function analysis, and identify the components that need to be developed.

**Week 5:** Learn AWS security services, analyze system functions, and finalize the Frontend interface layout.

**Week 6:** Learn AWS database services, finalize development technologies, and prepare the programming environment for the project.

**Week 7:** Set up the development environment, build Frontend interfaces, fix data display issues, and complete assigned interface features.

**Week 8:** Test the system, fix interface issues after integration, coordinate AWS deployment, and complete project documentation.
