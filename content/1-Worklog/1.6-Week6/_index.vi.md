### Kết quả đạt được tuần 6:

* Hiểu được các dịch vụ cơ sở dữ liệu trên AWS:
  
  Amazon RDS  
  Amazon Aurora  
  Amazon Redshift  
  Amazon ElastiCache  

* Thực hành tạo và kết nối Amazon RDS, tìm hiểu cách quản lý, sao lưu và khôi phục dữ liệu.

* Biết được khái niệm Database Migration và vai trò của AWS DMS, AWS SCT trong quá trình di chuyển dữ liệu.

* Hiểu được cách Frontend giao tiếp với Backend thông qua RESTful API và các dữ liệu cần sử dụng trên từng màn hình.

* Thống nhất công nghệ phát triển dự án:
  
  Backend: Django  
  Database: PostgreSQL  
  Docker  
  Frontend: Django Template + Bootstrap  

* Xác định vai trò phụ trách Frontend, chuẩn bị môi trường và kế hoạch triển khai giao diện cho Sprint tiếp theo.
