### Kết quả đạt được tuần 7:

* Hoàn thành thiết lập môi trường phát triển và làm quen với cấu trúc source code của dự án.

* Xử lý lỗi hiển thị ảnh bìa sách:
  
  Bổ sung trường lưu đường dẫn hình ảnh

  Cập nhật script import dữ liệu CSV  

* Hoàn thiện giao diện hệ thống:

  Xử lý lỗi modal xác nhận xóa  
  Cải thiện giao diện Dashboard thủ thư  

* Xây dựng giao diện tính năng quản lý mức phí phạt:
  
  Trang danh sách tiền phạt  
  Form cập nhật mức phí  
  Kiểm tra xử lý dữ liệu khi thay đổi mức phí  

* Kiểm tra và sửa lỗi giao diện trong quá trình tích hợp, đảm bảo các chức năng Frontend hoạt động ổn định.
